# Website admin ownership

The admin shell is shared, but each website owns its own navigation and workflows.

- `justindematteis/`: portfolio, Work Posts, AI Posts, project/recruitment tools.
- `justconsignin/`: consignment-site leads, content, website and social tools.
- `sunwings/`: Service Posts, Location Posts, Quote Requests and Sunwings settings.

Do not expose a feature in another site's config unless that website actually uses it. Sunwings service/location editors share one reusable post editor rather than copying the Justin or JustConsignIn editors.
